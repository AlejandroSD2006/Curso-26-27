# PR02POO · Material del alumnado

Los tres enunciados están en docs/alumnado. Incluyen propósito, ejemplos de uso,
diagramas UML Mermaid, requisitos, casos de aceptación y criterios de evaluación.
Abre los archivos .md con un visor compatible con Mermaid para ver los diagramas.

En notebooks encontrarás 01_dataset_guiado.ipynb: resuelve la primera práctica
paso a paso y contiene su código completo y salidas. Las prácticas 2 y 3 se
entregan como enunciados para resolver. Este paquete no incluye las guías docentes.

Para el cuaderno utiliza Python 3.10 o posterior en JupyterLab o un editor con
soporte Jupyter. Sus ejemplos no necesitan archivos externos ni paquetes de IA.
Ejecuta las celdas en orden y reinicia el kernel antes de comprobar el resultado final.
